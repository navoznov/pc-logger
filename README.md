# PC Logger

Отслеживает, соблюдается ли за компьютером режим «N минут за ПК — N минут перерыв»,
и строит локальный HTML-отчёт. Windows, системный трей, данные никуда не уходят.

## Что именно записывается

Только **факт** ввода, посекундно: была ли активность клавиатуры или мыши, была ли
активность геймпада, какое приложение было в фокусе. Коды нажатых клавиш не читаются
и нигде не сохраняются, низкоуровневые хуки клавиатуры не используются.

Раз в десять секунд к этому добавляется список приложений с видимыми окнами — из него
строится дорожка «Игра».

## Установка

Скачать архив со страницы релизов, распаковать **целиком** в любую папку и запустить
`PcLogger.exe`. Устанавливать .NET не нужно, рантайм внутри.

Папку `dashboard` рядом с exe удалять нельзя — без неё не откроется отчёт.

Автозапуск при входе в систему:

```
PcLogger.exe --install     # регистрирует задачу в планировщике
PcLogger.exe --uninstall   # убирает её
```

Права администратора не нужны: задача создаётся для текущего пользователя.

## Меню в трее

| Пункт | Что делает |
|---|---|
| **Отчёт** | Собирает HTML и открывает его в браузере |
| **Открыть папку данных** | `%LOCALAPPDATA%\PcLogger` — база и конфиг |
| **Игровые папки** | Открывает `config.json` в блокноте |
| **Выход** | Убирает иконку и завершает запись |

## Игровые папки

`config.json` в папке данных:

```json
{
  "game_folders": [
    "D:\\Steam\\steamapps\\common",
    "D:\\Games"
  ]
}
```

Игрой считается любой исполняемый файл внутри этих папок. Список читается **в момент
построения отчёта**, а не при записи: добавили папку, сохранили, нажали «Отчёт» — игровая
дорожка перекрасилась задним числом по всей истории, без перезапуска приложения.

Сломанный или пустой конфиг не мешает отчёту: игровая дорожка останется пустой,
всё остальное построится как обычно.

## Как читать отчёт

Четыре дорожки над общей осью времени:

```
ПК включён   ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░
Активность   ░▓▓▓▓░░░░▓▓▓▓░░░░▓▓▓▓▓▓░░░░░
Игра         ░████▒▒▒▒████▒▒▒▒██████░░░░░    █ в фокусе · ▒ в фоне
Режим        [  ок  ][перерыв][  ок  ]
```

- **ПК включён** — были ли вообще записи. Пусто означает, что компьютер был выключен
  или спал, а не что за ним никого не было.
- **Активность** — был ли ввод. Отсутствие ввода при включённом ПК читается как «отошёл».
- **Игра** — контекст, а не обвинение: на вердикт по режиму она не влияет никогда.
- **Режим** — блоки и перерывы. Блоки с превышением помечены штриховкой, а не только
  цветом.

Выделите мышью любой участок любой дорожки — внизу появится статистика за период:
время за ПК, время не за ПК с разбивкой на «отходил» и «ПК был выключен», проценты
и соотношение.

Ползунки внизу меняют пороги режима и пересчитывают вердикт **по всей истории сразу**.
Вердикт считается в браузере, поэтому пересборка отчёта для этого не нужна.

## Что считается перерывом

Блок режется отсутствием ввода, а не сменой окна. Поставить игру на паузу, не выходя
из неё, и уйти — это перерыв: окно игры остаётся на переднем плане, но ввода нет.

Паузы делятся на три класса:

| Длительность | Что происходит |
|---|---|
| меньше `micro_gap` (3 мин) | поглощается блоком |
| от `micro_gap` до `break_minutes` | блок продолжается: слишком коротко для отдыха |
| `break_minutes` (15 мин) и больше | блок закрывается, перерыв засчитан |

## Разработка

```
dotnet test tests/PcLogger.Core.Tests    # 92 теста
npm test                                 # 28 тестов
dotnet run --project tools/DemoReport    # отчёт на синтетических данных
```

`PcLogger.Core` не содержит ни одной Windows-зависимости и собирается где угодно.
`PcLogger.App` нацелен на `net8.0-windows`, но благодаря `EnableWindowsTargeting`
публикуется и с macOS:

```
dotnet publish src/PcLogger.App -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

## Что хранится

`%LOCALAPPDATA%\PcLogger\pclogger.db` — SQLite. Десятисекундные бакеты: время начала,
сколько секунд из десяти был ввод, сколько был геймпад, какое приложение было в фокусе.
Плюс справочник путей и интервалы жизни процессов с окнами.

Отчёт показывает последние 90 дней.
