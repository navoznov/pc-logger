# PC Logger Localization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Дать отчёту и трею английский язык, переключаемый в самом отчёте, так чтобы добавление третьего языка сводилось к правке двух словарей.

**Architecture:** Словари отчёта — обычный dashboard-скрипт `i18n.js` рядом с `render.js`: существующие правила `csproj` уже копируют его рядом с exe и вшивают в сборку, а `ReportBuilder.Render` уже инлайнит его в отчёт. Семь строк трея живут отдельным `Strings.cs` в Core (не в App: на macOS WinForms-слой компилируется, но не выполняется). Язык по умолчанию вычисляется из `CultureInfo.CurrentUICulture` и едет в payload как `lang`; выбор пользователя перекрывает его через `localStorage`.

**Tech Stack:** .NET 8 (C#), xUnit, ES5-совместимый ванильный JS в UMD-обёртке, `node --test`.

**Spec:** `docs/superpowers/specs/2026-09-12-i18n-design.md`

**Отличие от §6 спеки:** спека ставит английский перевод отдельным шагом после проводки шаблона. План авторит оба словаря в задаче 2, потому что тест паритета ключей (§5.1) иначе остаётся красным на протяжении двух задач. Проводка шаблона после этого только потребляет ключи.

## Global Constraints

- Русский текст в ключах переносится **дословно**. Это не повод переписывать формулировки; любая правка русского текста — отдельная задача вне этого плана.
- Ключи — семантические, точечные, всегда **строковые литералы** в исходниках. Конкатенация ключей (`t('track.' + id + '.name')`) запрещена: она ослепляет проверку связности из задачи 6.
- Служебные ключи начинаются с `$` (сейчас только `$name`) и исключены из проверки на мёртвые ключи.
- Фолбэк `t()`: текущий язык → `en` → сам ключ. Никаких пустых строк.
- Файлы `dashboard/*.js` пишутся в стиле соседей: `'use strict'`, UMD-хвост `(typeof module !== 'undefined' && module.exports ? module.exports : window)`, `function` вместо стрелок в коде, который читает браузер отчёта.
- Не трогать: `clock()` в `render.js`, `ratio.toFixed(1)`, формат даты `MM-DD`, персистентность темы, `docs/known-limitations.md`, документы в `docs/superpowers/`.
- Базовая линия перед началом: `node --test` — 69 тестов зелёные; `dotnet build PcLogger.sln` — 0 warnings, 0 errors.
- Коммиты: Conventional Commits, английский, императив. Без `Co-Authored-By` и без пометок о генерации.

```csharp
using System.Globalization;

namespace PcLogger.Core.Localization;

/// <summary>
/// The seven strings the tray and the startup failure path need. Lives in Core rather than
/// in App because the WinForms layer can be compiled but not executed off Windows, and the
/// resolution rule is the part worth testing.
/// </summary>
public static class Strings
{
    private const string Fallback = "en";

    public static IReadOnlyDictionary<string, IReadOnlyDictionary<string, string>> All { get; } =
        new Dictionary<string, IReadOnlyDictionary<string, string>>
        {
            ["ru"] = new Dictionary<string, string>
            {
                ["tray.report"] = "Отчёт",
                ["tray.dataFolder"] = "Открыть папку данных",
                ["tray.gameFolders"] = "Игровые папки",
                ["tray.quit"] = "Выход",
                ["tray.failureTip"] = "PC Logger — сбой записи ({n})",
                ["tray.failureBalloon"] = "Запись прервана: {message}",
                ["app.startupFailed"] = "PC Logger не смог запуститься:\n\n{message}"
            },
            ["en"] = new Dictionary<string, string>
            {
                ["tray.report"] = "Report",
                ["tray.dataFolder"] = "Open data folder",
                ["tray.gameFolders"] = "Game folders",
                ["tray.quit"] = "Quit",
                ["tray.failureTip"] = "PC Logger — recording failure ({n})",
                ["tray.failureBalloon"] = "Recording stopped: {message}",
                ["app.startupFailed"] = "PC Logger could not start:\n\n{message}"
            }
        };

    /// <summary>The language the whole application speaks, fixed at process start.</summary>
    public static string Current { get; } = Resolve(CultureInfo.CurrentUICulture);

    public static string Resolve(CultureInfo culture)
    {
        var code = culture.TwoLetterISOLanguageName;
        return All.ContainsKey(code) ? code : Fallback;
    }

    /// <summary>
    /// An unknown key returns itself: a key on screen is a visible bug, which is what we
    /// want, rather than a blank label nobody notices.
    /// </summary>
    public static string Get(string key) =>
        All[Current].TryGetValue(key, out var text) ? text : key;
}
```

- [ ] **Step 3: Написать каркас модуля**

Создать `src/PcLogger.Core/dashboard/i18n.js` — сначала только механика, словари заполняются следующим шагом:

```js
(function (root) {
  'use strict';

  // Every user-visible string in the report. Keys are semantic rather than English text:
  // half of these are two-sentence tooltips, which make unreadable keys and break on any
  // editorial change — and a semantic key privileges neither language.
  const DICTS = {
    ru: { $name: 'Русский' },
    en: { $name: 'English' }
  };

  const FALLBACK = 'en';
  let current = FALLBACK;

  function set(lang) { current = DICTS[lang] ? lang : FALLBACK; }
  function lang() { return current; }
  function langs() { return Object.keys(DICTS); }

  // A key that reaches the screen is a visible bug, which is the point: a blank label or an
  // "undefined" would hide a missing translation instead of reporting it.
  function t(key, params) {
    let text = DICTS[current][key];
    if (text === undefined) text = DICTS[FALLBACK][key];
    if (text === undefined) return key;
    if (!params) return text;

    return text.replace(/\{(\w+)\}/g, function (whole, name) {
      return params[name] === undefined ? whole : String(params[name]);
    });
  }

  root.I18n = { t: t, set: set, lang: lang, langs: langs, DICTS: DICTS };
})(typeof module !== 'undefined' && module.exports ? module.exports : window);
```

```js
// The header, the sliders, the legend, the track names and the table head are not repainted
// by redraw(), so one pass fills them — at startup and again whenever the language changes.
function applyStatic() {
  const fill = function (attribute, apply) {
    document.querySelectorAll('[' + attribute + ']').forEach(function (node) {
      apply(node, I18n.t(node.getAttribute(attribute)));
    });
  };
  fill('data-i18n', function (node, text) { node.textContent = text; });
  fill('data-i18n-title', function (node, text) { node.title = text; });
  fill('data-i18n-aria', function (node, text) { node.setAttribute('aria-label', text); });
}
```

```js
function describeAt(zoneId, hit, t) {
  if (zoneId === 'intensity') {
    return { what: I18n.t('cursor.intensity', { pct: intensityAt(t) }) };
  }

  const name = I18n.t(TRACK_NAMES[zoneId]);
  // Today's lane runs to midnight while the data stops at the moment the report was built,
  // and “the PC was off” about eight o'clock tonight is a claim the report cannot make.
  if (!hit) {
    return { what: name + ' · ' +
      (t >= DATA.generated ? I18n.t('cursor.future') : I18n.t(NOTHING_AT[zoneId])) };
  }

  const when = clockOf(hit.t) + '–' + clockOf(hit.t + hit.d) + ' · ' +
               Render.fmtDuration(hit.d);
  const item = hit.item;
  let what;

  if (zoneId === 'tPower') what = I18n.t(item.s === 'away' ? 'cursor.away' : 'cursor.input');
  else if (zoneId === 'tActive') what = I18n.t('cursor.input');
  else if (zoneId === 'tGame') what = I18n.t(item.lvl === 'fg' ? 'cursor.game.fg' : 'cursor.game.bg',
                                             { app: item.app });
  else if (item.s === 'off') what = I18n.t('cursor.off');
  else if (item.kind === 'break') what = I18n.t('cursor.break');
  else if (item.kind === 'short') what = I18n.t('cursor.short');
  else what = I18n.t(item.verdict === 'over' ? 'cursor.block.over' : 'cursor.block.ok');

  return { what: name + ' · ' + what, when: when };
}
```
